# PinEase 项目检查（2026-10-25）

## 结论

完成源码、状态机、摄像头生命周期、校准/眨眼、存储和统计、主题与组件、桌面权限、资源及依赖检查。本次修复了正常构建无法发现的会话竞态、切页采集、久坐提醒及统计问题。

检查采用真实业务模块配合可控时钟、存储和媒体对象，不代表真人识别效果或硬件端到端测试。

## 已修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 切换到历史/设置会卸载采集使用的视频元素 | Worker 不再收到新画面，监测停滞 | 没有可用预览时使用独立视频采集源，关闭时一并释放 |
| 被取消的旧启动请求随后报错 | 清空新会话的 stream | 先核对启动代次，再更新共享状态 |
| 关闭旧摄像头对象操作共享预览 | 新摄像头已接上也被清空 | 只清理仍绑定本对象媒体流的视频 |
| 结束会话异步保存后再次清空 session | 新开始的会话可能丢失 | 保存独立旧会话快照；异步等待前完成共享状态清理 |
| 锁屏/切后台时摄像头尚在加载 | 原 pause 对 loading 不生效，可能随后打开摄像头 | 加载中暂停直接取消启动；pagehide 同步切换到暂停状态 |
| 更改音量等设置重置久坐提醒 | 频繁调整可不断推迟休息提醒 | 仅改变久坐设置时重算提醒阈值 |
| 跨午夜区间全部归入起始日 | 日统计和区间内会话列表不准确 | 按本地日期重叠比例分摊秒数，并筛选跨日会话 |
| 桌面权限只接受摄像头 | 通知被拒绝，开发地址相机也受影响 | 增加严格的应用/配置本机源检查，支持通知和视频，继续拒绝音频、屏幕捕获及第三方源；同时实现 request/check 回调 |
| 备份可包含非法日期、反向日期和不一致秒数 | 统计异常，或侧面参考缺失仍显示正常 | 验证日期、区间秒数、汇总一致性和侧面头颈参考；存储入口也限制 10 MB |
